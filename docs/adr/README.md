# Architectural decision records

ADRs preserve the context behind consequential decisions. New ADRs use the next zero-padded number and include these sections:

1. `Status`
2. `Context`
3. `Decision`
4. `Consequences`
5. `Alternatives considered`

An ADR is not a substitute for implementation tests. It records why a decision is safe enough to test and gives future contributors a way to revisit it without erasing history.
