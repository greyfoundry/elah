# Elah 0.0.1: Genesis release gate

Genesis is the laboratory foundation for Elah. It establishes the repository, project contracts, build foundations, upstream-study isolation, generated-interface checks, and automated quality gates needed for subsequent engineering.

It is not a release for Minecraft server operators. Genesis implements no gameplay behavior and does not provide a runnable Minecraft cluster, a playable world, or a distributed handoff demonstration.

## Demonstrated foundation

The Genesis gate covers the following repository-level capabilities:

- Rust, Java, Node, and Protocol Buffers build foundations with pinned toolchain inputs.
- Contract documents, architecture decision records, and an explicit failure model.
- Generated Protocol Buffers output checked against its manifest.
- Isolation of upstream-study material from production sources, build inputs, packages, releases, dependency graphs, containers, and SBOM inputs.
- Continuous-integration checks for formatting, compilation, tests, protocol linting and builds, generated output, provenance, licensing, dependency changes, static analysis, and an SBOM artifact.

These gates make the foundation reproducible and reviewable. They do not establish distributed runtime correctness.

## Not included

The following are deliberately outside the Genesis release gate and must not be inferred from the repository foundations:

- Folia worker runtime integration or a runnable Folia deployment.
- Mineflayer laboratory-client scenarios.
- A Minecraft proxy or a runnable multi-worker cluster.
- Player, entity, or inventory handoffs across a fixed boundary.
- Chaos, crash-recovery, storage, durability, or soak-test evidence.
- Dynamic placement, autoscaling, generation services, or production operator workflows.

The planned sequence is maintained in the [roadmap](../../ROADMAP.md). Its stages are future engineering work, not status claims for Genesis.

## Reproducing the release gate

Prepare the versions in [Toolchains](../development/toolchains.md), then run the local baseline from the repository root:

```sh
just check
pnpm ci:check
reuse lint
git diff --check
```

The checks above validate source and repository artifacts. They are not a substitute for a Minecraft integration, gameplay, chaos, storage, or soak workload, and Genesis does not include such a workload.

See [CI and local checks](../development/ci.md) for the mapping between local commands and continuous-integration jobs.
