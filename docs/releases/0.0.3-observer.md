# 0.0.3 — Observer

Observer adds the first read-only Elah administrator command for offline Minecraft Java Anvil worlds:

```text
elah observe <world>
elah observe <world> --deep
```

Standard mode validates the world tree, saved level metadata, dimension layout, all terrain region headers, and occupied chunk envelopes. Deep mode additionally fingerprints complete payload inputs and boundedly decodes every occupied chunk. Both modes repeat evidence collection and produce no report if the selected world changes.

## Release evidence

The required GitHub check `Observer Laboratory (standard, deep, immutable, fail-closed)`:

1. creates and rereads deterministic positive, negative, multi-region, multi-dimension, and semantic chunk fixtures with the pinned PrismarineJS development oracle;
2. runs standard and deep `elah.observe/v1` reports;
3. compares counts, dimensions, saved data versions, and statuses with oracle truth;
4. compares complete SHA-256 inventories before and after both scans;
5. runs the synchronized changed-world CLI harness, which requires exit 5 and zero success-report bytes;
6. uploads `elah.observer-laboratory/v1` and `elah.observer-comparison/v1` evidence only after every assertion passes;
7. removes the temporary fixture in all outcomes.

The release remains gated by the repository's Rust, Java, Node, Buf, generated-output, studying-boundary, public-provenance, licensing/REUSE, dependency-review, SBOM, CodeQL, Protocol Laboratory, and Observer Laboratory checks.

## Scope boundary

This release does not implement Folia or Velocity integration, server runtime hooks, gameplay, ownership, storage writes, persistence services, failover, repair, handoff, placement, or a production cluster. It does not prove player activity. It does not make a live world safe to inspect without external snapshot coordination.

See the [Observer operator guide](../development/observer.md) and [ADR 0007](../adr/0007-read-only-observer.md) for limits, provenance, exits, recovery, and design decisions.
