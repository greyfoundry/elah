# Elah 0.0.5 - Folia Baseline Laboratory

Folia Baseline Laboratory is a development-only functional compatibility release. It pins Folia 1.21.8 build 6 at commit `612d9bd8569fe1a6008a05325af3fad66ef1cef7` with Mineflayer 4.37.1 and Minecraft 1.21.8.

## Release gate

The required GitHub Actions job runs 32 sessions in two sequential waves of 16. Every session must connect, log in, spawn, record a Folia-observed position, request deterministic movement, record a second Folia-observed position, request disconnect, and end. Server-observed movement must meet the fixed threshold. Folia must then receive a clean stop request, exit with code zero, and use no signal.

After clean Folia shutdown, the gate hashes the complete world tree, runs standard and deep Observer reports, and hashes the world again. The standard report must validate region and chunk envelopes without decoded content. The deep report must decode every occupied chunk within Observer's fixed limits. The complete before and after snapshots must describe an unchanged world.

Passing evidence uses `elah.folia-baseline/v1`. It references the client report, both Observer reports, both world snapshots, and their SHA-256 digests. An independent verifier rereads those bounded regular files and rejects changed counts, lifecycle, compatibility, semantics, paths, or digests. Failures use `elah.folia-baseline-error/v1` with a stable kind, failed phase, plain summary, and bounded diagnostic reference.

The Folia artifact is accepted only with this [official PaperMC build metadata](https://fill.papermc.io/v3/projects/folia/versions/1.21.8/builds/6):

```text
Artifact: folia-1.21.8-6.jar
Bytes: 53064151
SHA-256: 233843cfd5001b6f658fcab549178d694cc37f0277d004ea295de0a94c57278f
```

The fixture binds only to loopback. The EULA acceptance, JAR, configuration, world, logs, and process root are disposable. The JAR and world are not redistributed.

## Qualification boundary

This release adds no operator command. Observer remains the current operator-useful surface. Passing evidence is functional-only and applies only to the exact tuple above.

It does not prove performance, Folia region parallelism, Elah integration, ownership, handoff, placement, storage, failover, gameplay, a playable cluster, plugin compatibility, or production readiness. Upstream Folia's [region architecture](https://github.com/PaperMC/Folia#overview) motivates later work, but this release does not measure region concurrency.
