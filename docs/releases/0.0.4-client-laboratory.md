# Elah 0.0.4 - Client Laboratory

Client Laboratory is a development-only compatibility and lifecycle release. It qualifies Mineflayer 4.37.1 with Minecraft 1.21.8 and Paper build 60 using a real Paper server on a GitHub-hosted runner.

## Release gate

The required job runs 32 sessions in two sequential waves of 16. Every session must connect, log in, spawn, record a Paper-observed position, request deterministic movement, record a second Paper-observed position, request disconnect, and end. Horizontal server-observed movement must be at least 0.5 blocks. Paper must receive a clean stop request and exit with code zero.

Passing evidence uses `elah.client-laboratory/v1`. Failed evidence uses `elah.client-laboratory-error/v1` and cannot be confused with a pass. Failure summaries and Paper diagnostics are bounded. A client failure disconnects peers and still attempts server cleanup.

The Paper object is fetched over HTTPS with redirects disabled, a fixed size limit, and this pinned identity:

```text
Version: 1.21.8
Build: 60
SHA-256: 8de7c52c3b02403503d16fac58003f1efef7dd7a0256786843927fa92ee57f1e
```

The EULA acceptance, JAR, configuration, logs, and world exist only inside the disposable laboratory workspace. The JAR and world are not redistributed. The server binds to loopback and needs no Minecraft account credentials.

## Compatibility boundary

Minecraft 1.21.11 is not qualified because hosted candidate evidence showed client-local movement that Paper did not accept. Minecraft 26.2 is also unqualified because upstream client support remains unresolved. Qualification does not roll forward from 1.21.8 without a new pinned tuple and evidence run.

This release adds no operator command. Observer remains the current operator-useful surface. Client Laboratory does not prove Folia, ownership, placement, storage, failover, gameplay, a playable cluster, or production readiness.
